# Общее описание решения

## Для чего нужен проект

Проект предназначен для вычисления периметров и площади геометрических фигур на языке Python: треугольника, прямоугольника и круга. 

Проект состоит из модулей:

`perfg.py` - программа содержит функции для вычисления периметров геометрических фигур: треугольника, прямоугольника и круга.
`plosfg.py` - программа содержит функции для вычисления площади геометрических фигур: треугольника, прямоугольника и круга.
