# Описание функций

## Файл `plosfg.py`

### Функция `triangle(a, h)`

**Назначение:** вычисляет площадь произвольного треугольника.

**Параметры:** 
- `a` - основание произвольного треугольника
- `h` - высота произвольного треугольника

**Возвращает:** площадь произвольного треугольника.

**Примеры вызова:**

> ```python```
print (triangle(3, 6)) _# возвращает ответ 18_

### Функция rectangle(a, b)

**Назначение:** вычисляет площадь прямоугольника.

**Параметры:** 

- `a` - длина прямоугольника
- `b` - ширина прямоугольника

**Возвращает:** площадь прямоугольника.

**Примеры вызова:**

> ```python```
print (rectangle(5, 2)) _# возвращает ответ 10_

### Функция circle (r)

**Назначение:** вычисляет площадь круга.

**Параметры:** 

- `r` - радиус круга

**Возвращает:** площадь круга.

**Примеры вызова:**

> ```python```
print (circle(4)) _# возвращает ответ 50.24_

## Файл `perfg.py`

### Функция `triangle(a, b, c)`

**Назначение:** вычисляет периметр треугольника.

**Параметры:** 

- `a`, `b`, `c` - длины сторон треугольника.

**Возвращает:** периметр треугольника.

**Примеры вызова:**

> ```python```
print (triangle(3, 4, 5)) _# возвращает ответ 12_

### Функция rectangle(a, b)

**Назначеие:** вычисляет периметр прямоугольника.

**Параметры:**

**Возвращает:** периметр прямоугольника.

**Пример вызова:**

> ```python```
print (rectangle(5, 2)) _# возвращает ответ 20_

### Функция circle (r)

**Назначене:** вычисляет периметр круга.

**Параметры:**

- `r` - радиус круга.

**Возвращает:** периметр круга.
