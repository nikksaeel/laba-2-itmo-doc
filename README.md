# laba-2-itmo-doc

Программы для вычисления площади и периметра фигур

## Автор

_Исаева Елизавета Николаевна, группа M3107, SE, университет ИТМО_

## Установка

Скопируйте код ниже и вставьте его в терминал

> git clone https://github.com/nikksaeel/laba-2-itmo-doc.git

## Запуск

> python3 perfg.py
> python3 plosfg.py

## Описания файлов

`perfg.py` - вычисляет периметры таких фигур, как: треугольник, прямоугольник, круг

`plosfg.py` - вычисляет площади таких фигур, как: треугольник, прямоугольник, круг

## Возможные проблемы при запуске
 
1) Не смешите меня, их нет

2) Смотрите п.1
